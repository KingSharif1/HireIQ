Self-hosted web fonts (latin subset, variable `wght` axis), downloaded from Google Fonts on 2026-11-23.
All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).

- `inter-latin-var.woff2` — Inter (wght 300–700)
- `syne-latin-var.woff2` — Syne (wght 500–800)
- `dm-sans-latin-var.woff2` — DM Sans (wght 400–700)

Loaded via `next/font/local` in `app/layout.tsx` so builds don't fetch from Google.
