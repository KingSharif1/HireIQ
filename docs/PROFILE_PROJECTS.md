# Recruiter-ready project blurbs

Curated case-study copy for HireIQ profile / GitHub enrich. Facts only — no invented metrics.

## HireIQ
**One-liner:** AI resume tailoring + application tracking so job-search paperwork gets finished.
**Problem:** Rewriting resumes per posting and losing track of applications.
**Built:** Next.js/TypeScript, Claude tailoring, ATS scoring, tracker, GitHub evidence, export.
**Result:** Live at hireiq.kingsharif.com; used in real tailor → track → apply workflows.
**Stack:** Next.js, TypeScript, Supabase, Claude, Tailwind

## RideNEMT
**One-liner:** Ops SaaS for non-emergency medical transport — scheduling, trips, billing.
**Problem:** Operators juggle spreadsheets, phone tag, and disconnected billing.
**Built:** Multi-tenant TypeScript platform for operators and riders.
**Result:** Deployed product direction at app.ridenemt.com (production learnings from NEMT Billing).
**Stack:** TypeScript, React, Express, Supabase, Stripe

## NEMT Billing (DfwNemt)
**One-liner:** Trip-to-pay calculator and invoicing for NEMT — live with paying customers.
**Problem:** Broker trip exports don't map cleanly to driver pay.
**Built:** Next.js + Strapi + Postgres + Stripe; tiered rates; PDF/spreadsheet pay breakdowns.
**Result:** 5 paying companies; ~50–100 calculations/month each (~80–500 trips per run). Live: nemtbiling.com
**Stack:** Next.js 14, Strapi, PostgreSQL, Stripe

## Roomba
**One-liner:** Live ops dashboard for a DIY Roomba — dock, runs, map, camera, controls.
**Problem:** Hardware telemetry is useless without a clear operator UI.
**Built:** Next.js dashboard over a ROS 2 / Pi stack.
**Result:** Deployed at roomba.kingsharif.com — hardware-adjacent full-stack signal.
**Stack:** TypeScript, Next.js, ROS 2

## Nami
**One-liner:** Personal finance app with real bank data via Plaid.
**Problem:** Generic budgeting UIs miss safe-to-spend, pass-throughs, recurring cashflow.
**Built:** Next.js + Supabase + Plaid production sync; RLS; AI advisor over real transactions.
**Result:** Live UI at nami.kingsharif.com — fintech/backend credibility.
**Stack:** Next.js, Supabase, Plaid
